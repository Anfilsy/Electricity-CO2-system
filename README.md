## 1. Project Overview
This repository contains the GAMS optimization model, input data, and plotting scripts developed coupled electricity-CO2 system in China's power sector decarbonization.

The framework enables:

1. Scenario-based system optimization

2. Techno-economic analysis

3. Figure reproduction using processed model outputs

## 2. Reproduction Workflow
### 2.1 Run Optimization Model
If reproducing optimization from scratch:

1. Navigate to:
```
Optimization_model/
```
2. Ensure the model reads input data from:
```
Input_data/
```
3. Run the `Electricity-CO2 system.gms` file using GAMS.

4. Input data and results are transferred into optimization model through `.gdx` files. Ensure that the required files have been generated from the input data or model results and that their paths and filenames match the model’s loading statements.

6. The model will generate .gdx output files upon completion.

### 2.2 Generate Figures
1. Navigate to:
```
Figure_plotting/
```
2. Each folder contains plotting code `.py, .ipynb, or .r` and the required datasets, exported from `.gdx` files generated by the GAMS optimization models.

3. The processed datasets are then used to generate figures using plotting scripts. Figures are saved in the output directory defined within each plotting script.
